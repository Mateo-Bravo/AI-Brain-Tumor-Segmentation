# 🎮 Atajos de Teclado - Visor Médico

## ✅ **CAMBIO REALIZADO**
**La tecla ESC ahora NO TIENE PROGRAMACIÓN - comportamiento 100% nativo del navegador**
- ESC funciona automáticamente con F11 (sin interferencias)
- Todas las demás funciones tienen teclas específicas
- Comportamiento completamente nativo y confiable

---

## 📋 **Atajos de Teclado Actualizados**

### 🖼️ **Pantalla Completa (100% Nativo)**
| Tecla | Función | Descripción |
|-------|---------|-------------|
| **F11** | Activar pantalla completa | Pantalla completa del navegador |
| **ESC** | Salir de pantalla completa | **AUTOMÁTICO DEL NAVEGADOR** - sin programación |

### 🎛️ **Interfaz**
| Tecla | Función | Descripción |
|-------|---------|-------------|
| **F1** | Maximizar/Restaurar visor | Oculta/muestra paneles laterales |

### 🔍 **Zoom**
| Tecla | Función | Descripción |
|-------|---------|-------------|
| **Z** | Activar zoom | Activa la herramienta de zoom |
| **Q** | Desactivar zoom | Desactiva la herramienta de zoom |
| **R** | Reset zoom | Vuelve al tamaño original (100%) |

### 📏 **Mediciones**
| Tecla | Función | Descripción |
|-------|---------|-------------|
| **M** | Toggle medición | Activa/desactiva herramienta de medición |
| **N** | Cerrar menú mediciones | Cierra el menú de opciones de medición |

### ➕ **Crosshairs**
| Tecla | Función | Descripción |
|-------|---------|-------------|
| **C** | Toggle crosshairs | Activa/desactiva las líneas de referencia |

### ❌ **ANTES (ESC programado):**

### ✅ **AHORA (ESC 100% nativo):**
- **ESC** → Sin programación, funciona automáticamente con F11
- **Q** → Desactivar zoom
- **M** → Toggle medición  
- **N** → Cerrar menú mediciones
- **Z** → Activar zoom (nuevo)

## 🎯 **Flujo de Trabajo Recomendado**

### Para Zoom:
1. **Z** → Activar zoom
2. Usar mouse para hacer zoom
3. **R** → Reset zoom si necesario
4. **Q** → Desactivar zoom

### Para Mediciones:
1. **M** → Activar medición
2. Hacer mediciones con mouse
3. **N** → Cerrar menú si está abierto
4. **M** → Desactivar medición

### Para Pantalla Completa:
1. **F11** → Pantalla completa
2. **ESC** → Salir de pantalla completa (automático)
